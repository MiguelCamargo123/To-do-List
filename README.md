# To-do-List

This is a to-do list with the purpose to train Python and programming logic

## 🧮 Functions
- To add a task in the list
- List the tasks of the list
- Remove tasks of the list

### Prerequisites

   ```bash

3. Run the code
   ```bash
   python To-doList.py
